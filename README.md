# RainWorld-FriendlyVulture
RU-Мод позволяющий вам приручить стервятников,королевских стервятников,стрижей и стрижей стервятников  (приручение работает как с ящерами тоесть дать еду и он приручен но не вся еда приручит с 1 раза) ENG-Rain World mod: tame Vultures, King Vultures, Miros Birds and Miros Vultures by feeding them.
